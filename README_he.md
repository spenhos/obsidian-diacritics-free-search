## הבעיה

אם הרשימות שלך מכילות עברית מנוקדת כמו **בְּרֵאשִׁית**, חיפוש **בראשית** (ללא ניקוד) לא ימצא את הטקסט. אותו הדבר קורה עם **café** מול **cafe**, ערבית **بِسْمِ** מול **بسم**, וכל סימן דיאקריטי אחר.

**Diacritics-Free Search** פותר את זה על ידי הפיכת כל הסימנים הדיאקריטיים לשקופים בזמן החיפוש — הקלד בלי סימנים ומצא טקסט שיש בו.

```
שאילתת חיפוש:    בראשית        →  מוצא:  בְּרֵאשִׁית ✓
שאילתת חיפוש:    cafe           →  מוצא:  café ✓
שאילתת חיפוש:    بسم            →  מוצא:  بِسْمِ ✓
```

## תכונות

### 🔍 חיפוש מקומי — חיפוש והחלפה בהערה הנוכחית

<table>
<tr>
<td width="120"><strong>קיצור</strong></td>
<td><kbd>Option</kbd> + <kbd>F</kbd> <em>(מומלץ — הקצו בהגדרות ← קיצורי מקלדת)</em></td>
</tr>
<tr>
<td><strong>התנהגות</strong></td>
<td>פותח סרגל חיפוש בראש ההערה (בסגנון Chrome)</td>
</tr>
</table>

**יכולות:**

- **הדגשה בזמן אמת** — כל ההתאמות מסומנות בצהוב; ההתאמה הנוכחית בכתום
- **ניווט בין התאמות** — השתמש בכפתורי ▲▼ או <kbd>Enter</kbd> / <kbd>Shift+Enter</kbd> לקפוץ בין תוצאות
- **סמנים בפס הגלילה** — נקודות צהובות בצד ימין מראות היכן נמצאות ההתאמות (ניתן ללחוץ עליהן!)
- **החלף אחד / החלף הכל** — החלף את ההתאמה הנוכחית או את כולן בבת אחת
- **מתג רגישות לאותיות** — לחץ על "Aa" כדי להפעיל/לכבות רגישות לאותיות גדולות/קטנות
- **זוכר חיפוש אחרון** — פתח מחדש את הסרגל והחיפוש הקודם שלך עדיין שם
- **Escape לסגירה** — לחץ <kbd>Esc</kbd> מכל מקום (גם תוך כדי עריכה) לסגירת הסרגל

### 🌐 חיפוש גלובלי — חיפוש בכל הכספת

<table>
<tr>
<td width="120"><strong>קיצור</strong></td>
<td><kbd>Shift</kbd> + <kbd>Option</kbd> + <kbd>F</kbd> <em>(מומלץ — הקצו בהגדרות ← קיצורי מקלדת)</em></td>
</tr>
<tr>
<td><strong>התנהגות</strong></td>
<td>פותח חלון לחיפוש בכל קבצי ה-Markdown בכספת</td>
</tr>
</table>

**יכולות:**

- **חיפוש בכל הכספת** — סורק כל קובץ `.md`
- **הקשר מודגש** — מציג את השורה עם הטקסט שנמצא מודגש
- **לחיצה לניווט** — לחץ על כל תוצאה כדי לפתוח את הקובץ ולקפוץ להתאמה המדויקת
- **ספירת התאמות לכל קובץ** — ראה כמה התאמות יש בכל קובץ
- **החלף הכל גלובלי** — החלף מונח בכל הקבצים בלחיצה אחת
- **קלט עם השהייה** — ממתין 300ms אחרי שמפסיקים להקליד כדי למנוע עיכוב בכספות גדולות

### 🎯 איך ההתאמה עובדת

התוסף משתמש בנרמול Unicode NFD כדי לפרק תווים, ואז מסיר את כל הסימנים המשולבים (קטגוריית Unicode `Mn`):

| מקור | מנורמל | כתב |
|------|--------|------|
| בְּרֵאשִׁית | בראשית | עברית (ניקוד + טעמים) |
| café | cafe | לטינית (הטעמה) |
| بِسْمِ ٱللَّهِ | بسم الله | ערבית (תשכיל) |
| naïve | naive | לטינית (דיאֶרֶזיס) |
| Ἀθῆναι | Αθηναι | יוונית (פוליטונית) |
| résumé | resume | לטינית (הטעמות מרובות) |
| über | uber | לטינית (אומלאוט) |

> 💡 **שני הצדדים מנורמלים** — אם אתה מחפש *עם* סימנים דיאקריטיים, זה עדיין מוצא טקסט *בלי* (ולהפך).

### ⌨️ קיצורי מקלדת

| פעולה | קיצור |
|-------|-------|
| פתח חיפוש מקומי | <kbd>Option</kbd> + <kbd>F</kbd> *(מומלץ — הקצו בהגדרות ← קיצורי מקלדת)* |
| פתח חיפוש גלובלי | <kbd>Shift</kbd> + <kbd>Option</kbd> + <kbd>F</kbd> *(מומלץ — הקצו בהגדרות ← קיצורי מקלדת)* |
| התאמה הבאה | <kbd>Enter</kbd> או כפתור ▼ |
| התאמה קודמת | <kbd>Shift</kbd> + <kbd>Enter</kbd> או כפתור ▲ |
| סגור חיפוש | <kbd>Esc</kbd> (עובד מכל מקום) |
| החלף נוכחי | <kbd>Enter</kbd> בשדה ההחלפה |

שתי הפקודות זמינות גם דרך **לוח הפקודות** (<kbd>Cmd</kbd> + <kbd>P</kbd>).

## התקנה

### התקנה ידנית

1. הורד `main.js` ו-`manifest.json` מה-[release האחרון](https://github.com/spenhos/obsidian-diacritics-free-search/releases)
2. צור תיקייה: `<הכספת-שלך>/.obsidian/plugins/diacritics-free-search/`
3. הנח את שני הקבצים בתוכה
4. הפעל מחדש את Obsidian
5. עבור ל-**Settings → Community Plugins** → הפעל "Diacritics-Free Search"

### בנייה מקוד מקור

```bash
git clone https://github.com/spenhos/obsidian-diacritics-free-search.git
cd obsidian-diacritics-free-search
npm install
npm run build
```

העתק `main.js` + `manifest.json` לתיקיית התוספים של הכספת שלך.
